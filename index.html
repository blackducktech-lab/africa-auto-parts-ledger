將帳本安裝成手機 App

Install on iPhone & Android Home Screen

您的手機支援一鍵直接安裝！ / One-Tap Install Available

iPhone / iPad 使用 Safari 瀏覽器安裝
  1. 1 請確認您是用手機內建的 Safari 瀏覽器開啟此網頁（若從 LINE 點開，請先點右下角選單「用預設瀏覽器開啟」）。
  2. 2 點擊螢幕最下方正中央的 「分享」按鈕（方框向上箭頭圖示 ⍗）。
  3. 3 往下滑動選單，點擊 「加入主畫面」 (Add to Home Screen)，再按右上角「新增」即可！
Android 安卓 使用 Chrome 瀏覽器安裝
  1. 1 使用 Google Chrome 瀏覽器開啟此網頁。
  2. 2 點擊右上角的 「⋮」三個點選單。
  3. 3 選擇 「安裝應用程式」 或 「加到主畫面」 (Install App)，桌面就會出現專屬 App 圖示！
